# 🌐 Animated Portfolio Website

A sleek, responsive, and fully customizable **Portfolio Website** built using **React.js** and **Tailwind CSS**.
## 🚀 Live Demo

🔗 [GitHub Profile](https://github.com/Rimjhim018)

## 🛠️ Tech Stack

- ⚛️ React.js
- 🎨 Tailwind CSS
- 💾 Vercel(for deployment)

## 📁 Features

- Responsive design for all screen sizes 📱💻
- Smooth scroll and animation effects ✨
- Clean and modular React components 🧩
- Easy to customize with Tailwind utility classes 🎯
- Professional sections: About, Skills, Projects, Contact, etc. 👨‍💻


## 🧑‍💻 How to Use

### 1. Clone the Repo

```bash
git clone https://github.com/Rimjhim018/Rima-s-Portfolio-main.git
cd Rima-s-Portfolio-main
````

### 2. Install Dependencies

```bash
npm install
```

### 3. Run the App

```bash
npm.cmd run dev
```

### 4. Build for Production

```bash
npm run build
```
